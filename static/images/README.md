# Hacking Theme Background Image

## Instructions

1. **Place your background image here:**
   - File name: `hacking-bg.jpg` (or `.png`)
   - Recommended size: 1920x1080 or larger
   - Format: JPG or PNG

2. **Supported file names:**
   - `hacking-bg.jpg`
   - `hacking-bg.png`
   - `hacking-bg.webp`

3. **The image will automatically be used as the background for the Hacking Theme**

## Current Setup

The CSS is configured to use `/static/images/hacking-bg.jpg` as the background.

If you have a different file name, update `themes.css`:
```css
background-image: url('/static/images/YOUR_IMAGE_NAME.jpg') !important;
```

## Image Description (for reference)

The background should be:
- Dark, menacing atmosphere
- Cool blue and purple tones
- Ominous and powerful aesthetic
- Fits the cyberpunk/hacking theme
