📚 Help & Documentation

🚀 Welcome to Auto_Punch IDE

Your powerful VS Code + Cursor clone with AI assistance and RedTeam tools.

Quick Start

  • Open Command Palette: Press Ctrl+Shift+P
  • Toggle Terminal: Press Ctrl+`
  • Save File: Press Ctrl+S
  • Open File: Press Ctrl+O
  • New File: Press Ctrl+N

Features

  • 🤖 Auto_Punch AI Assistant - Full unrestricted AI capabilities
  • 🔧 RedTeam Toolkit - Security tools integration
  • 📝 Monaco Editor - VS Code-like editing experience
  • 🌐 Browser Preview - Preview web pages
  • 🔐 SSH Connections - Remote server management
  • 📦 Extensions - Extend functionality

Getting Started

  1. Open a workspace folder using the File Explorer
  2. Start coding with full AI assistance
  3. Use the Command Palette for quick actions
  4. Explore the RedTeam Toolkit for security tools

📖 Documentation

Core Features

  • Monaco Editor: Full-featured code editor with syntax highlighting, IntelliSense, and more
  • File Explorer: Navigate and manage your workspace files
  • Terminal: Integrated terminal with support for PowerShell, CMD, and Bash
  • Git Integration: Source control with Git commands

AI Features

  • HacxGPT: Full unrestricted AI model for any task
  • Natural Language Automation: Execute commands using natural language
  • Terminal Automation: AI-powered terminal command execution

RedTeam Toolkit

  • Security Tools: Nmap, Burp Suite, and more
  • Tool Categories: Network scanning, web testing, exploitation, and more
  • Quick Access: Launch tools directly from the IDE

Extensions

💡 Tips & Tricks

Productivity Tips

  • Use Ctrl+Shift+P to quickly access any command
  • Press Ctrl+P to quickly open files by name
  • Use multiple cursors with Alt+Click or Ctrl+D
  • Format code with Shift+Alt+F
  • Use the Command Palette to search for settings

AI Assistant Tips

  • Ask the AI to explain code, write functions, or debug issues
  • Use natural language to describe what you want to accomplish
  • The AI can execute terminal commands and manage files
  • Enable auto-execution for faster workflow

Customization

  • Change themes in Settings → Appearance
  • Adjust font size and editor preferences
  • Configure terminal shell and settings
  • Customize keyboard shortcuts (coming soon)
